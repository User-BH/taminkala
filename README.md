# سایت تأمین کالا باختر

> طراحی و توسعه: **شرکت رهوار پیوند داده**

سایت معرفی شرکت تأمین کالا باختر به‌همراه پیکربندی سرور برای سامانه‌های داخلی.

## ساختار روی سرور

یک آدرس (دامنه یا IP)، هر سرویس روی پورت جداگانه:

| سرویس | پورت پیش‌فرض | محل فایل‌ها |
|---|---|---|
| سایت معرفی شرکت | `80` | `/opt/taminkala/public` (از همین مخزن) |
| سامانه پیچک (استعلام چک) | `8081` | `/opt/pichak` با venv خودش — Nginx فقط به `127.0.0.1:8088` پراکسی می‌کند |
| سامانه بیمه و حواله | `8082` | `/var/www/bime/index.html` |

- هیچ مسیری از سایت اصلی به سامانه‌ها نمی‌رسد؛ `آدرس/pichak` یا هر آدرس ناموجود دیگر،
  صفحه **۴۰۴ با قالب تأمین کالا** را نشان می‌دهد (روی هر سه پورت).
- پیچک باید فقط روی `127.0.0.1` گوش دهد (`PICHAK_BIND=127.0.0.1:8088`) تا مستقیم از بیرون در دسترس نباشد.

## نصب و به‌روزرسانی (برای همه، بدون نیاز به دانش فنی)

### بار اول
روی سرور (اوبونتو/دبیان):
```bash
git clone https://github.com/User-BH/taminkala.git /tmp/taminkala
sudo bash /tmp/taminkala/deploy/taminkala.sh install
```
اسکریپت چند سؤال می‌پرسد (آدرس مخزن، پورت‌ها، دامنه)؛ برای قبول مقدار پیش‌فرض فقط Enter بزنید.

> اگر مخزن خصوصی است، اسکریپت در صورت خطا روش اضافه کردن کلید SSH (Deploy key) یا توکن را توضیح می‌دهد.

### دفعات بعد
```bash
sudo taminkala            # منوی ساده
sudo taminkala update     # دریافت آخرین نسخه و اعمال آن
sudo taminkala status     # وضعیت و بررسی سلامت هر سه سرویس
sudo taminkala rollback   # برگشت به نسخه قبل از آخرین به‌روزرسانی
sudo taminkala settings   # تغییر پورت‌ها، دامنه و مسیرها
```

ویژگی‌های اسکریپت:
- قبل از اعمال، پیکربندی Nginx را تست می‌کند؛ اگر خطا داشت تنظیمات قبلی را برمی‌گرداند و سایت فعلی از کار نمی‌افتد.
- اگر روی سرور فایلی دستی تغییر کرده باشد، قبل از به‌روزرسانی از آن پشتیبان می‌گیرد (`/etc/taminkala/backups`).
- پورت‌های تکراری یا اشغال‌شده را تشخیص می‌دهد و در صورت فعال بودن `ufw` پورت‌ها را باز می‌کند.
- تنظیمات در `/etc/taminkala/taminkala.env` (بیرون از مخزن) ذخیره می‌شود و با به‌روزرسانی پاک نمی‌شود.
- سامانه پیچک (`/opt/pichak`) را تغییر نمی‌دهد.

### عیب‌یابی پیچک
```bash
sudo bash /opt/taminkala/deploy/pichak-doctor.sh
```
بدون هیچ تغییری روی سرور، وضعیت پورت‌ها (از جمله 2083)، سرویس پیچک، نصب بودن tesseract و تنظیم OCR را
بررسی می‌کند و چند نمونه کپچای زنده را همراه با خروجی خام OCR در یک فایل `tar.gz` ذخیره می‌کند.

### افزودن سرویس جدید در آینده
۱. فایل‌های آن را به مخزن اضافه کنید.
۲. یک بلوک `server` با پورت جدید در `deploy/nginx/taminkala.conf.template` اضافه کنید (و در صورت نیاز متغیر پورت در `deploy/taminkala.sh`).
۳. روی سرور: `sudo taminkala update`

## سایت معرفی

سایت استاتیک و تک‌صفحه‌ای (HTML/CSS/JS خالص) در پوشه `public/`.
هم‌راستا با طراحی سامانه‌های پیچک و بیمه/حواله (رنگ قرمز `#cf1725`، گرادیان تیره–زرشکی، فونت وزیرمتن).

- **حالت روشن / تاریک**: پیش‌فرض روشن است؛ کاربر با دکمه بالای صفحه می‌تواند تاریک کند و انتخابش ذخیره می‌شود (با ریلود یا بازدید بعدی همان حالت می‌ماند).
- **واکنش‌گرا**: دسکتاپ، تبلت و موبایل.
- بخش‌ها: هیرو، آمار، درباره ما، حوزه فعالیت (غذایی، بهداشتی، شوینده، نوشیدنی)، خدمات، فرآیند همکاری، برندها، گالری، همکاری، تماس.

### قرار دادن عکس‌ها
جای عکس‌ها خالی و هاشورخورده است. فایل را با نام زیر در مسیر گفته‌شده بگذارید (در مخزن commit کنید و `sudo taminkala update` بزنید)؛ خودکار نمایش داده می‌شود:

| فایل | محل نمایش |
|---|---|
| `public/assets/img/photos/hero.jpg` | عکس اصلی بالای صفحه (عمودی، حدود ۱۲۰۰×۱۳۰۰) |
| `public/assets/img/photos/about-1.jpg` | ساختمان / دفتر مرکزی (عمودی) |
| `public/assets/img/photos/about-2.jpg` | تیم (مربع) |
| `public/assets/img/photos/about-3.jpg` | قفسه‌های انبار (مربع) |
| `public/assets/img/photos/cat-food.jpg` | مواد غذایی (۴:۳) |
| `public/assets/img/photos/cat-hygiene.jpg` | بهداشتی (۴:۳) |
| `public/assets/img/photos/cat-detergent.jpg` | شوینده (۴:۳) |
| `public/assets/img/photos/cat-beverage.jpg` | نوشیدنی (۴:۳) |
| `public/assets/img/photos/gallery-1.jpg` … `gallery-4.jpg` | گالری |
| `public/assets/img/photos/map.jpg` | تصویر نقشه |
| `public/assets/img/brands/brand-1.png` … `brand-8.png` | لوگوی برندهای همکار (PNG بدون پس‌زمینه) |

عکس‌ها را قبل از آپلود فشرده کنید (حداکثر ~۳۰۰KB؛ jpg یا webp).

### مواردی که باید با اطلاعات واقعی جایگزین شوند
- اعداد بخش آمار و نشان «سال همراهی» (`data-count` و متن همان تگ در `public/index.html`) — مقادیر فعلی نمونه هستند
- نشانی، تلفن، ایمیل و ساعات کاری در بخش تماس
- لینک شبکه‌های اجتماعی در فوتر
