# سایت معرفی شرکت تأمین کالا باختر

سایت استاتیک و تک‌صفحه‌ای (HTML/CSS/JS خالص، بدون نیاز به سرور خاص یا build).
هم‌راستا با طراحی سامانه‌های پیچک و بیمه/حواله (رنگ قرمز `#cf1725`، گرادیان تیره–زرشکی، فونت وزیرمتن).

## امکانات
- **حالت روشن / تاریک / خودکار**: به‌طور پیش‌فرض با تنظیم دستگاه کاربر هماهنگ است؛ با دکمه بالای صفحه بین «خودکار ← روشن ← تاریک» جابه‌جا می‌شود و انتخاب کاربر ذخیره می‌شود.
- **واکنش‌گرا (Responsive)**: دسکتاپ، تبلت و موبایل (منوی کشویی در موبایل).
- بخش‌ها: هیرو، آمار، درباره ما، حوزه فعالیت (غذایی، بهداشتی، شوینده، نوشیدنی)، خدمات، فرآیند همکاری، برندها، گالری، همکاری، تماس.

## قرار دادن عکس‌ها
جای همه عکس‌ها خالی و هاشور خورده است. کافی است فایل را با نام زیر در مسیر گفته‌شده بگذارید؛ به‌طور خودکار جایگزین می‌شود (نیازی به ویرایش HTML نیست):

| فایل | محل نمایش |
|---|---|
| `assets/img/photos/hero.jpg` | عکس اصلی بالای صفحه (عمودی، حدود ۱۲۰۰×۱۳۰۰) |
| `assets/img/photos/about-1.jpg` | ساختمان / دفتر مرکزی (عمودی) |
| `assets/img/photos/about-2.jpg` | تیم (مربع) |
| `assets/img/photos/about-3.jpg` | قفسه‌های انبار (مربع) |
| `assets/img/photos/cat-food.jpg` | مواد غذایی (۴:۳) |
| `assets/img/photos/cat-hygiene.jpg` | بهداشتی (۴:۳) |
| `assets/img/photos/cat-detergent.jpg` | شوینده (۴:۳) |
| `assets/img/photos/cat-beverage.jpg` | نوشیدنی (۴:۳) |
| `assets/img/photos/gallery-1.jpg` … `gallery-4.jpg` | گالری |
| `assets/img/photos/map.jpg` | تصویر نقشه (یا iframe نقشه را جایگزین کنید) |
| `assets/img/brands/brand-1.png` … `brand-8.png` | لوگوی برندهای همکار (PNG بدون پس‌زمینه) |

عکس‌ها را قبل از آپلود فشرده کنید (حداکثر ~۳۰۰KB؛ فرمت jpg یا webp).

## مواردی که باید با اطلاعات واقعی جایگزین شوند
- اعداد بخش آمار و نشان «سال همراهی» (`data-count` و متن داخل همان تگ در `index.html`)
- نشانی، تلفن، ایمیل و ساعات کاری در بخش تماس
- لینک شبکه‌های اجتماعی در فوتر

## اجرا
فایل `index.html` را مستقیم باز کنید یا پوشه را روی هر وب‌سرور (Nginx/Apache) قرار دهید.
برای تست محلی: `python3 -m http.server 8000`
